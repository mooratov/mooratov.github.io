A book recommendation engine built with collaborative filtering using matrix factorization. The system learns latent user and item factors from rating data to predict preferences and surface relevant recommendations.

## Approach

- Matrix factorization of the user-item rating matrix
- Hyperparameter tuning for latent factor dimensionality and regularization
- Evaluation against held-out ratings

## Tools

Python, NumPy, Pandas, Scikit-learn, Jupyter
