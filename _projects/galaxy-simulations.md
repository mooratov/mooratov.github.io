Analysis code for the FIRE (Feedback In Realistic Environments) cosmological simulations of galaxy formation. This work supported multiple published papers on galactic winds and feedback processes.

## Highlights

- Processed and visualized 50+ TB of simulation output data
- Built interpretable predictive models for galactic wind generation using engineered features with multiple regression and probabilistic modeling
- Contributed to 15+ publications with 3800+ total citations

## Tools

Python, C/C++, HPC clusters, Matplotlib
